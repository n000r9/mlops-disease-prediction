# MLOps Disease Prediction

An end-to-end machine learning project demonstrating the complete MLOps lifecycle.

## Project Overview

This project builds a machine learning system for disease prediction and applies MLOps practices throughout the model lifecycle.

## MLOps Components

- Git & GitHub
- Data Versioning with DVC
- Experiment Tracking with MLflow
- Model Training & Evaluation
- Model Registry
- Docker
- FastAPI
- CI/CD with GitHub Actions
- Model Deployment
- Model Monitoring
- Data Drift Detection
